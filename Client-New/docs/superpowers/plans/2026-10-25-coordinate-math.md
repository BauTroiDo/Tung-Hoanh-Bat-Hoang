**Architecture:** Finite planar point/bounds and paired anchors feed AffineMapTransform. Fit uses origin-relative coordinates and a relative degeneracy check. World height/provenance/readiness stays with scene integration and evidence documents.
**Tech stack:** Unity 6000.6.7f1 / Domain noEngineReferences, NUnit EditMode; isolated .NET 8 harness uses installed Unity SDK for early numerical tests.
**Spec:** docs/CN02_COORDINATE_EVIDENCE.md.
**Execution:** Native implementation as requested by user. No delegated agents. Isolated checkout avoids shared Editor/files.

## Global constraints / review focus

- CN01 independent PASS before production integration; no modifications to Antigravity World/scene/build files.
- At least three paired non-collinear points, finite/invertible output; reject near singular fits.
- Bounds inclusive, valid negative coordinates allowed. No Unity height computation.
- Large offsets should not erase local displacement. No implicit verified-calibration status.
- A fourth holdout measures residual but cannot promote synthetic fixtures to verified data.
